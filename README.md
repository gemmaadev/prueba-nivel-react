# Product Catalog App - React

A web application that displays a product catalog with list and detail views, developed with React and TypeScript.

## Prerequisites

- Node.js (v18 or higher)

## Installation

```bash
npm install
```

## Running the application

```bash
npm run dev
```

## Running the tests

```bash
npm test
```

## Technologies used

- React 19
- TypeScript
- React Router v7
- Vite
- Vitest + React Testing Library
- Tailwind CSS
